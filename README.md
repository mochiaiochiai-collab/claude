# うらないの部屋

家族の名前と生年月日を入れると、四柱推命・九星気学・西洋占星術を重ねて
「この家、こんな家やで」を関西弁のレポートで出す占いアプリです。ビルド不要、`index.html` を開くだけで動きます。

## イベントでの使い方（iPad → お客さんのケータイ）

1. iPad で生年月日（と名前）を入れて「家族まとめて占う」
2. 結果の上に QR コードが出る。お客さんがケータイのカメラで読みとる
3. お客さんのケータイで「Download」を押すと、結果のHTMLファイルが保存される（ケータイ幅で読める。あとからファイルで見返せる）
4. 「次のお客さんへ」で入力を全部消す

QR コードには結果やなく、生年月日と名前だけを URL の「#」の後ろに入れてます（4人で約140文字）。
ケータイはページ（index.html・style.css・family.js、圧縮して約29KB）を読み込んで、その中で占いを計算し直します。
「#」より後ろはサーバーに送られへんので、生年月日は公開先のサーバーにも残りません。
iPad は最初にページを開いたあとは通信を使いません（QR の部品 vendor/qrcode.js も最初に読み込みます）。

公開先は `family.js` の `SITE_URL`（GitHub Pages）です。

## 入力

- 名前は何でもOK。生年月日は数字ボタンで8桁（例：20130401）。
- 最初は4人分。「＋ 人を足す」で10人まで増やせます。

## 結果レポート（保存されるHTML）

1. 3つの占い（四柱推命・九星気学・西洋占星術）でひとりずつ
2. これから10年の流れ（全員の年齢を2年ごとの年表で。★は九星の節目、山場）
3. これからどう育ってく？？（五行のつながり、ひとりずつの育ち方、一個だけ注意）
4. 円満・開運ポイント

### 計算に使う中身（旧・長い版の項目）

1. 顔ぶれ（日柱・九星・星座・ひとこと）
2. 家の構造：日干の五行で「誰が誰を生かすか」（相生の流れ、誰からも養われてへん人）、世代と星座エレメントの対応
3. ひとりずつ：日干・日支・九星・太陽星座と月星座、これからの10年（毎年の天干と日干の関係＝通変星）と九星の節目（本命星が中宮に入る年）
4. 子ども世代の関わり方、いちばん注意したい組と仲裁役（通関）、親世代2人の相性
5. まとめの図、2人ずつの相性一覧、根拠

世代は生年月日が15年以上離れたところで自動的に分けています。学年は4/2〜翌4/1生まれを同学年として計算します。

## 計算の前提

- 日柱は 1900/1/1 = 甲戌 を基準に計算。年は立春（2/4目安）、月は節入りの目安日で切り替え。
- 九星は立春で区切った生まれ年から本命星を算出。
- 月星座は日本時間の正午で簡易計算（境目の人は時刻次第で変わる旨を表示）。
- 生まれた時刻は使わないので、時柱・アセンダント・大運は出しません。

## テスト

```sh
node test.js       # 計算の照合（参照ライブラリとの突き合わせ）＋ランダム500家族
node check.js      # ランダムな1万家族でレポートの矛盾をチェック（数秒）
node check.js 100000
```

`check.js` は占いのコードをそのまま動かして、出てきたレポートを読んで次を確かめます（AIは使いません）。

- 見出し・表・時期の欄の年齢が、その日の満年齢とそろってる
- 時期の期間が「いま」から始まって、立春の前日で区切られ、すきまなく続く。期間の年齢・学年が正しい
- 表の日柱・九星、個人の欄の日干の説明が、その人のもの
- 同じ段落が2回出てない（同じ日干・同じ星座・生年月日が同じ人がいても）
- 相性の平均点やいちばんのコンビが、一覧の点数とつじつまが合ってる
- undefined や空のカッコが出てない、名前がエスケープされてる

※ 占いはエンタメです。科学的根拠はありません。
